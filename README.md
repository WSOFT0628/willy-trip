# 🧭 Willy Trip

**Willy Trip** 是一套以行動裝置為核心設計的隨身旅行與行程管理系統。

它不只是「看行程表」，而是希望在旅行前、旅行中與旅行後，都能協助管理：

- 即時時間與定位天氣
- 下一趟旅程與倒數
- 單日／多日旅行
- 完整行程與行事曆
- 住宿資訊
- 附近探索
- 多旅程管理
- 行程文件匯入
- 歷史旅程
- 原始附件
- JSON 備份與還原

目前採用純前端架構，可部署於 **GitHub Pages**，手機瀏覽器即可直接使用。

# 🏠 今日

首頁是旅行當下的主要 Dashboard。

目前提供：

- 24 小時制即時時鐘
- 日期與星期
- GPS 定位
- 即時天氣
- 未來天氣入口
- 下一趟旅程
- 出發倒數
- 第一站／下一站
- 關鍵提醒
- 附近探索

## 首頁旅程判斷

v1.8.1 起，首頁不再直接依賴 `activeTripId`。

首頁選擇規則：

1. 今天有正在進行的旅程 → 顯示今天的旅程
2. 今天沒有旅程 → 顯示最近的未來旅程
3. 歷史旅程永遠不會自動成為首頁主旅程

因此查看或編輯歷史旅行，不會再把歷史行程錯誤帶回首頁。

# 🌤️ 定位天氣

Willy Trip 可透過 Geolocation API 取得目前位置並顯示：

- 所在地
- 目前溫度
- 天氣狀況
- 體感溫度
- 降雨資訊
- 風速
- 濕度
- 今日最高／最低溫
- 未來 6 小時最高降雨機率

點擊 **「查看未來天氣」** 可查看未來 6 小時逐時預報與今天／明天天氣。

# 🗺️ 旅程

# ✏️ 規劃

規劃頁是目前的 **旅程管理中心**。

旅程會依日期自動分類：

- 🟢 進行中
- 🧳 未來旅程
- 🕘 歷史旅程

每趟旅程可查看、編輯、複製、封存、刪除與管理原始附件。

---

# 🧳 多旅程管理

Willy Trip 已從單一旅程架構升級成：

```text
trips[] + activeTripId
```

系統可以同時保存多趟旅行，不需要為了建立下一趟行程而覆蓋目前資料。

---

# 📄 行程文件匯入

Willy Trip 支援從 `.docx` 行程文件建立旅程。

用途不限於歷史旅行，可將以前的 Word 行程匯入成歷史旅程，也可以先在 Word 規劃未來旅行，再匯入 Willy Trip。

系統會嘗試解析：

- 旅程名稱
- 開始／結束日期
- 交通方式
- Day 1 ～ Day N
- 景點
- 飲食
- 地址
- 住宿
- Check-in
- 訂房資訊

匯入後，系統會依日期自動判斷為未來旅程、進行中旅程或歷史旅程。

# 📎 原始附件
