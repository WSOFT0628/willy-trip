# 🧭 Willy Trip

**Willy Trip** 是一套以行動裝置為核心設計的隨身旅行與行程管理系統。

它不只是用來「查看行程表」，而是希望在旅行進行中協助使用者掌握：

-   現在的時間與所在地
-   即時天氣與後續天氣變化
-   下一個行程與導航
-   單日／多日旅行規劃
-   住宿資訊
-   附近生活機能
-   行程進度
-   旅行資料備份與還原

目前採用純前端架構，可部署於 GitHub Pages，使用手機瀏覽器即可直接使用。

# ✨ 主要功能

## 🏠 旅行首頁

首頁作為旅行中的主要 Dashboard，目前提供：

-   24 小時制即時時鐘
-   日期與星期
-   GPS 目前位置
-   即時天氣
-   下一趟旅程
-   出發倒數
-   第一站／下一站預覽
-   一鍵導航
-   附近快速搜尋

首頁資訊依用途分成：

**現在 → 天氣 → 旅程 → 第一站／下一站 → 附近探索**

避免相同資訊在不同卡片重複出現。

------------------------------------------------------------------------

## 🌤️ 定位天氣

Willy Trip 可使用瀏覽器 Geolocation API 取得目前 GPS
位置，再依所在地取得天氣資訊。

首頁顯示：

-   所在地
-   目前溫度
-   天氣狀況
-   體感溫度
-   即時降雨資訊
-   風速
-   濕度
-   今日最高溫
-   今日最低溫
-   未來 6 小時最高降雨機率

### 天氣詳情

為避免首頁資訊過度擁擠，逐時預報不再常駐首頁。

點擊天氣區塊或：

**「查看未來天氣 ›」**

即可開啟天氣詳情。

目前支援：

-   未來 6 小時逐時天氣
-   每小時溫度
-   每小時降雨機率
-   天氣圖示
-   今天／明天天氣
-   每日最高／最低溫
-   每日降雨機率

定位失敗或未授權定位時，可使用備援位置取得天氣資訊。

# 🗓️ 單日與多日旅行

Willy Trip 不限制旅行天數。

支援：

-   一日遊
-   兩天一夜
-   三天兩夜
-   多日旅行
-   機車旅行
-   汽車旅行
-   自訂交通方式

## 自適應日期顯示

單日旅程不會顯示多餘的 `Day 1`。

例如：

> 新竹一日遊\
> 2026/09/11（五）

多日旅行才會使用：

> Day 1｜第一天行程\
> Day 2｜第二天行程\
> Day 3｜第三天行程

------------------------------------------------------------------------

# ⚙️ 旅程設定

每趟旅程可設定：

-   旅程名稱
-   開始日期
-   結束日期
-   主要交通方式

每天可獨立設定：

-   日期
-   每日標題
-   當日交通方式
-   出發地
-   結束地
-   每日備註
-   多個行程點
-   當晚住宿

目前支援：

-   新增一天
-   刪除一天
-   複製本日
-   新增行程點
-   刪除行程點

------------------------------------------------------------------------

# 📍 行程點

每個行程點可保存：

-   預計時間
-   地點名稱
-   地址
-   備註
-   停留資訊

地址可直接開啟 Google Maps 導航。

旅行尚未開始時，首頁顯示：

**第一站預覽**

旅程開始後則切換為：

**下一站**

------------------------------------------------------------------------

# 🏨 住宿管理

住宿已從一般備註升級成獨立旅行資料。

每晚住宿可保存：

-   住宿名稱
-   住宿地址
-   入住時間
-   退房時間
-   訂房／訂單編號
-   住宿備註
-   停車資訊
-   早餐／門禁等補充資訊

完整行程中會以獨立住宿卡片呈現，住宿地址亦可直接導航。

------------------------------------------------------------------------

# 📍 附近探索

Willy Trip 可依照手機目前 GPS 位置搜尋旅行途中需要的設施。

搜尋中心會跟隨目前所在地，不會固定在旅程目的地。

## 🚗 交通／補給

-   🛵 機車停車場
-   🚗 汽車停車場
-   ⛽ 加油站
-   🏪 便利商店
-   🏧 ATM
-   🔋 充電站

## 🍽️ 吃東西／休息

-   🍽️ 餐廳
-   🍢 小吃
-   🥪 早餐
-   ☕ 咖啡廳
-   🌙 宵夜
-   🍰 甜點

## 🆘 臨時需求

-   🚻 公共廁所
-   💊 藥局
-   🏥 醫院／診所
-   👮 派出所

目前採用：

**GPS 定位 → Google Maps 附近搜尋**

因此不需要額外設定 Google Maps API Key。

# 💾 資料中心

Willy Trip 提供獨立的資料管理頁面。

目前支援：

-   完整 JSON 備份
-   JSON 完整還原
-   複製備份 JSON
-   查看資料摘要
-   最後備份時間
-   最後還原時間
-   重設旅程進度
-   清除 Willy Trip 本機資料

建議在以下時間建立完整備份：

1.  重大版本更新前
2.  正式旅行前
3.  旅行結束後

------------------------------------------------------------------------

# 🔄 舊版資料相容

Willy Trip 具備舊版資料 Migration 機制。

目前可處理：

-   舊版單日旅程 → 新版多日架構
-   舊版住宿文字 → 新版住宿資料結構
-   舊版旅程資料 → 新版資料 Schema

目標是降低版本更新造成旅行資料遺失的風險。

# 📌 專案理念

Willy Trip 希望解決的不是：

> 「如何把旅遊行程表做得漂亮？」

而是：

> **「旅行正在進行時，我現在在哪裡、接下來去哪裡、什麼時候該走，以及天氣和行程是否需要我調整計畫？」**

因此後續功能與 UI / UX 會持續以：

**「旅行途中是否真的方便使用」**

作為主要設計原則。
