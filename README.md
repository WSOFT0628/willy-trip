# 🧭 Willy Trip

**Willy Trip** 是一套以行動裝置為核心設計的隨身旅行與行程管理系統。

它不只是「看行程表」，而是希望在旅行前、旅行中與旅行後，都能協助管理：

- 即時時間與定位天氣
- 下一趟旅程與出發倒數
- 單日／多日旅行
- 個人出發地、集合點與團體正式出發
- 完整行程與行事曆
- 行程拖曳排序
- 文字行程快速匯入
- 住宿資訊
- 附近探索
- 多旅程管理
- 歷史旅程與原始附件
- 行程分享
- JSON 備份與還原

目前採用純前端架構，可部署於 **GitHub Pages**，手機瀏覽器即可直接使用。

## 🚩 出發流程

Willy Trip v1.9.6 將旅行開始前的資訊正式拆分：

```text
🏠 個人出發地
        ↓
📍 集合點
        ↓
🛵 團體正式出發
        ↓
🗺️ 第一個正式行程
```

例如：

```text
07:50  🏠 從家出發
09:00  📍 集合｜7-ELEVEN 嘉添門市
09:15  🛵 團體正式出發
10:30  🗺️ 內灣老街
```

「家」屬於個人出發資訊，不再被當成第一站；第一站預覽會顯示真正開始旅遊後的第一個行程點。

這種設計也適合多人出遊：每個人可以從不同區域出發，但共用同一個集合點與團體出發時間。

## 首頁旅程判斷

首頁選擇規則：

1. 今天有正在進行的旅程 → 顯示今天的旅程
2. 今天沒有旅程 → 顯示最近的未來旅程
3. 歷史旅程永遠不會自動成為首頁主旅程

因此查看或編輯歷史旅行，不會再把歷史行程錯誤帶回首頁。

# 📋 文字行程匯入

除了逐筆建立行程，Willy Trip 也支援直接貼上文字版行程。

例如：

```text
2026/9/11（星期五）新竹機車一日遊

09:00｜7-ELEVEN 嘉添門市集合
地址：新北市三峽區嘉添路109-2號1樓

09:15｜從嘉添門市出發
前往內灣老街。

10:30｜抵達內灣老街
稍微逛逛內灣老街＋范阿嬤野薑花肉粽。
```

系統會嘗試解析：

- 日期
- 旅程名稱
- 開始時間
- 結束時間
- `左右` 等模糊時間描述
- 地點名稱
- 地址
- 備註／活動內容
- 抵達與離開關係
- 集合資訊

解析完成後會先提供預覽，再由使用者決定建立新旅程或更新既有旅程，避免直接覆蓋資料。

# 🧳 多旅程管理

Willy Trip 採用：

```text
trips[] + activeTripId
```

系統可以同時保存多趟旅行，不需要為了建立下一趟行程而覆蓋目前資料。

旅程可以是：

- 未來規劃
- 正在進行
- 已完成的歷史旅行

# 📄 行程文件匯入

Willy Trip 支援從 `.docx` 行程文件建立旅程。

用途不限於歷史旅行，可以將以前的 Word 行程匯入成歷史旅程，也可以先在 Word 規劃未來旅行，再匯入 Willy Trip。

系統會嘗試解析：

- 旅程名稱
- 開始／結束日期
- 交通方式
- Day 1 ～ Day N
- 景點
- 飲食
- 地址
- 住宿
- Check-in
- 訂房資訊

匯入後會依日期自動判斷為未來旅程、進行中旅程或歷史旅程。

# 📌 專案理念

> **旅行正在進行時，我現在在哪裡、接下來去哪裡、什麼時候該走，以及行程是否需要調整？**

Willy Trip 希望把旅行拆成「規劃前、出發前、旅行中、旅行後」四個階段，而不是只保存一張靜態行程表。

旅行結束後，仍能保留過往行程、原始規劃文件與旅行紀錄，作為下一趟旅行的參考。
