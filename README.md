# 🧭 Willy Trip

**Willy Trip** 是一套以行動裝置為核心設計的隨身旅行與行程管理工具。\
目標不只是「查看行程表」，而是在旅行途中提供即時時間、定位天氣、導航、行程進度、資料備份，以及單日／多日旅程管理。

目前專案以 **GitHub Pages** 部署，採用純前端架構，方便手機直接開啟使用。

------------------------------------------------------------------------

## ✨ 目前版本

### v0.8.0 --- Multi-day Trip & Lodging Upgrade

本版本將 Willy Trip 從原本的一日遊工具，正式升級為可支援
**單日、兩天一夜、多日旅行** 的行程系統。

## 🚀 核心功能

### 🏠 隨身旅行首頁

-   24 小時制即時時鐘
-   日期與星期顯示
-   手機定位
-   依目前位置取得即時天氣
-   體感溫度
-   降雨機率
-   濕度
-   風速
-   旅程出發倒數
-   目前／下一站資訊
-   Google Maps 一鍵導航
-   行程進度顯示
-   日落時間與重要時間提醒

定位失敗或使用者未授權定位時，可使用預設備援位置取得天氣資訊。

------------------------------------------------------------------------

## 🗓️ 單日與多日旅行

Willy Trip 不侷限於一日遊。

支援：

-   一日遊
-   兩天一夜
-   三天兩夜
-   多日旅行
-   機車旅行
-   汽車旅行
-   其他自訂交通方式

### 自適應顯示

單日旅程：

> 新竹一日遊\
> 2026-09-11

不會多餘顯示 `Day 1`。

多日旅程則自動使用：

> Day 1｜第一天行程\
> Day 2｜第二天行程\
> Day 3｜第三天行程

------------------------------------------------------------------------

## ⚙️ 旅程設定

每趟旅程可設定：

-   旅程名稱
-   開始日期
-   結束日期
-   主要交通方式
-   每日行程

每一天可獨立設定：

-   日期
-   每日標題
-   當日交通方式
-   出發地
-   結束地
-   每日備註
-   多個行程點
-   住宿資訊

並支援：

-   新增一天
-   刪除一天
-   複製整天行程
-   新增行程點
-   刪除行程點

------------------------------------------------------------------------

## 📍 行程點

每個行程點目前可保存：

-   預計時間
-   地點名稱
-   地址
-   備註
-   預計停留資訊

行程頁可直接使用地址開啟 Google Maps。

------------------------------------------------------------------------

## 🏨 住宿管理

v0.8.0 起，住宿不再只是一般文字備註，而是正式的旅行資料。

每晚住宿可保存：

-   住宿名稱
-   地址
-   入住時間
-   退房時間
-   訂房／訂單編號
-   住宿備註
-   停車資訊
-   早餐、門禁等補充資訊

完整行程會將住宿獨立呈現，並支援住宿地址導航。

------------------------------------------------------------------------

## 💾 資料中心

Willy Trip 提供獨立的資料管理頁面。

目前支援：

-   完整 JSON 備份
-   JSON 完整還原
-   複製備份 JSON
-   查看目前資料摘要
-   顯示最後備份時間
-   顯示最後還原時間
-   重設旅程進度
-   清除本機 Willy Trip 資料

建議在：

1.  重大版本更新前
2.  正式旅行前
3.  旅行結束後

各建立一次完整備份。

------------------------------------------------------------------------

## 🔄 舊版資料相容

v0.8.0 具備舊版資料轉換機制。

可將先前版本的一日遊資料自動轉換成新版多日架構，並將舊版住宿文字轉換至新版住宿資料結構，降低版本升級造成資料遺失的風險。

## 🛠️ 技術架構

目前 Willy Trip 採用：

-   HTML
-   CSS
-   JavaScript
-   LocalStorage
-   Geolocation API
-   Open-Meteo 天氣資料

## 📌 專案理念

Willy Trip 希望解決的不是「如何把旅遊行程寫得漂亮」，而是：

> **旅行正在進行時，我現在在哪裡、接下來去哪裡、幾點該走，以及行程是否已經延誤？**

因此後續開發會持續以 **實際旅行途中是否方便使用** 作為主要 UI / UX
判斷標準。
